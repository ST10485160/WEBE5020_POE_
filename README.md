# Marconi Beam Secondary School Website

## Project Overview
This project is a website developed for Marconi Beam Secondary School. It provides information about the school, its academic programmes, admissions process and contact details.

## Website Pages
- **Home:** Introduction to the school.
- **About:** School background, mission and vision.
- **Academics:** Academic programmes and subjects offered.
- **Admissions:** Application information and admission requirements.
- **Enquiry:** An enquiry form for prospective learners and parents.
- **Contact:** Contact information and a contact form.

## Features
- Responsive website layout.
- Navigation between website pages.
- Interactive JavaScript features, including an accordion, search and image gallery with lightbox.
- Enquiry and contact forms with JavaScript validation.
- SEO elements, including page titles, meta descriptions, `robots.txt` and `sitemap.xml`.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub Pages
